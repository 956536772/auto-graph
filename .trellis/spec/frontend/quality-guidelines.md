# Quality Guidelines (Frontend)

## Overview
Quality is maintained through visual consistency and manual verification of interactivity.

## Standards

### Visual Consistency
- **Typography**: Prefer `'PingFang SC', 'Microsoft YaHei', sans-serif` for body text.
- **Colors**: Follow the established palette in `index.html`.
- **Layout**: Use cards with soft shadows (`box-shadow: 0 10px 30px rgba(0,0,0,0.08)`) and rounded corners (`16px`).

### Code Quality
- **Self-Documentation**: Use descriptive names for points and variables (e.g., `square`, `octagon`).
- **Comments**: Briefly explain the steps of board construction (e.g., "1. 定义正方形 ABCD").

### Verification
- **Drag-and-Drop**: Ensure all interactive points move as expected.
- **Label Editing**: Verify that double-clicking a label allows for renaming.
- **Cross-Browser**: Test in modern browsers (Chrome, Edge, Firefox).
